# Proposal: Flight Card Component

## Summary

Create a flight card molecule component that displays flight information including route, price, dates, and a CTA button. Used in search results and deal listings.

## Motivation

Core UI element needed for displaying flight offers throughout the application.

## Scope

- Create `FlightCard` molecule component
- Display origin → destination, price, dates, airline info
- Responsive layout (stacked on mobile, horizontal on desktop)
- Accessible with proper semantic markup
